# Creepify

**Creepify** is a dark, mysterious, and immersive horror-themed landing page designed to set the tone for haunted storytelling, horror games, ARG projects, or spooky digital experiences.

> “The horror begins here.”

## Features

- Fullscreen background with atmospheric artwork
- Clean, elegant text layout that blends with theme
- Mobile-responsive and cross-browser compatible
- SEO optimized with meta tags
- Favicon support for brand identity

## Tech Stack

- HTML5
- CSS3 (custom, no frameworks)
- Hosted on GitHub Pages

## Usage

1. Clone this repo or download ZIP  
2. Edit `index.html` and `styles.css` to personalize your text or layout  
3. Upload to GitHub for automatic hosting with GitHub Pages
